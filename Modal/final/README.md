# Modal Component 📦

A simple and reusable modal (popup) component. 
The modal can be opened and closed using buttons, clicking outside the modal, or pressing the Escape key.

---

## ✨ Features

- Open modal with a button
- Close modal by:
  - clicking the close button
  - clicking outside the modal
  - pressing the **Escape (ESC)** key
- Smooth overlay effect
- Clean and reusable structure

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)

---

## ▶️ How to Run

1. Download or clone the repository
2. Open the project folder
3. Open `index.html` in your browser

No build tools or dependencies required.
