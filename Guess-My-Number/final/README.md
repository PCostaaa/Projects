# Guess My Number 🎯

A simple number guessing game.  
The player must guess a secret number between **1 and 20**, with a limited score that decreases after each wrong guess.

---

## 🎮 How to Play

- The game generates a random number between 1 and 20
- You start with a score of 20
- Enter a number and click Check!
- Feedback is given:
  - 📈 Too high
  - 📉 Too low
  - 🎉 Correct number
- Each wrong guess decreases the score
- The game ends when the score reaches 0
- Click Again! to restart the game

---

## ✨ Features

- Random number generation
- Score system
- Highscore tracking
- Visual feedback for win/loss
- Reset game functionality
